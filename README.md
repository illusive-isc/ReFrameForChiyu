# ReFrame for Chiyu

ちゆ (plium) 用の ReFrame です。アバターに入っている衣装・髪・小物・ギミックのうち **使わないものにチェックを入れるだけで、アップロード時に自動で取り除きます。** 元のアセットは書き換えません。

## 導入

1. VCC に ReFrame のリポジトリを追加します: <https://reframe.illusive-isc.jp/>
2. `ReFrame for Chiyu` をプロジェクトに追加します。共通部分の ReFrameCore は一緒に入ります。

## 使い方

1. Hierarchy でちゆを右クリック → **ILLUSORY OVERRIDE → ReFrame → このアバターに ReFrame を追加**
2. `ReFrame` オブジェクトの Inspector で、使わない項目にチェックを入れます。チェックした項目は Scene と Hierarchy から消えて見えます。
3. いつもどおりアップロードします。

## 選べる項目

- **服**: カーディガン / ワンピース / ソックス / ローファー / ベレー帽 / 頭のリボン / ヘアピン / レギンス・パンツ / 下着
  - ソックス・ワンピースを「着たまま固定」にすると、その下に隠れる体のポリゴンも削ります (体の三角形が約半分になります)。
- **髪**: 耳・尻尾 / ツインテール / 横髪 / 前髪の長さ / 前髪の形 / 髪 (髪型を差し替えるとき。髪の揺れ物も消えます)
- **ギミック**: 胸の大きさ / 足: ヒールオフ・ハイヒール / ジャンプ・ダッシュ
- **表情**: まばたき OFF / 表情ロック / なでなで / 表情差分 / もぐもぐ / 表情プリセット (FaceEmo などで表情を作り直すとき。手の形は残ります)
- **小物**: 鞄 / 小物を触って操作 / 眼鏡 / 食べ物 / スマホ / ハンディファン / ぬいぐるみ
- **ロコモーション**: 立ち・しゃがみ・伏せのポーズ (番号を選んで焼き込み) / 浮遊 / ポーズの左右反転 / ジャンプモーション OFF / 移動モーション OFF / 足固定 / AFK / AFK のぬいぐるみ / エモート

## Quest 簡易対応版

Inspector 上部の **「Quest 簡易対応版を作成」** で Quest 用の設定が増えます。ビルドターゲットが Android のときに使われます。詳しくは ReFrameCore の README を見てください。ちゆ版では次のように初期設定しています。

- **揺れ物**: 前髪・ツインテール (左右)・尻尾・胸 (左右)・耳 (左右) の 8 本を残し、ほかを消す選択で作られます (Quest の上限 8 本・ボーン 64 に収まります)。一覧から変えられます。
- **色**: lilToon の見た目に合わせて明るさを調整済みです (髪とソックスは少し暗く、少し青寄りに)。法線マップの陰は焼き込みません。
- **顔**: 頬染めなどの半透明の重ね描きは Quest では描けないので切ります (涙・汗・コミカルの線は残ります)。
- スマホ (ライト付き) とジャンプ・ダッシュ (当たり判定付き) は Quest では自動で消えます。
- アバターに AAO (Avatar Optimizer) の **Trace And Optimize** を付けると、メッシュがまとまりランクが上がります。

## ちゆ差分プレハブセットと一緒に使う

[ちゆ差分プレハブセット](https://illusive-isc.booth.pm/items/9087398) (性格表情・尻尾の癖・体型・瞳のきらめき) と一緒に使えます。「表情差分」を固定すると、その系統の性格表情だけが残ります。「表情プリセット」を消すと性格表情も消えます (尻尾の癖・瞳のきらめきは残ります)。
